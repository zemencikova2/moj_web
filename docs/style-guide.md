# Dizajnový manuál

Vizuálna referencia pre tvorbu webu podľa [Matcha Tea](https://www.matchatea.sk/). Cieľom je zachovať svieži, prírodný a pokojný charakter značky a prispôsobiť ho obsahu vlastného webu.

## Farebná paleta

Paleta nižšie vychádza z CSS premenných priamo na referenčnej stránke.

| Farba | Použitie na referenčnej stránke |
| --- | --- |
| `#387931` | Hlavná zelená (`--color-primary`): primárne akcie, odkazy a výrazné akcenty. |
| `#76B729` | Jasná zelená (`--color-secondary`): sekundárne akcie a hover stav primárnej farby. |
| `#FFFFFF` | Biela (`--color-tertiary`): kontrastný povrch a pozadie hlavičky. |
| `#0F0F0F` | Základný tmavý text. |
| `#F5F6F8` | Veľmi svetlý sivý podklad zo štýlov stránky; používať striedmo vedľa bielej. |

Na svetlých plochách zachovaj vysoký kontrast textu. Zelenú používaj ako jasný akcent, nie ako náhradu za všetky neutrálne plochy.

## Typografia a písma

- **Rodina písma:** Mulish. CSS stránky nastavuje Mulish pre bežný text aj nadpisy.
- **Nadpisy:** Mulish s výraznejšou hrúbkou a jasnou veľkostnou hierarchiou.
- **Bežný text:** Mulish v normálnej hrúbke, s pohodlnou výškou riadku.
- **Záložné písmo:** `Arial, sans-serif`, ak Mulish nie je dostupný.
- Vyhni sa dekoratívnym písmam, ktoré by konkurovali produktovým fotografiám a zeleným akcentom.

## Tlačidlá a ovládacie prvky

- Primárne tlačidlo používa zelenú `#387931` a kontrastný svetlý text.
- Sekundárna zelená `#76B729` sa používa na sekundárne akcie a zvýraznené či hover stavy.
- Svetlé alebo biele tlačidlá používaj len tam, kde zostane zreteľný kontrast voči okoliu.
- Použi mierne zaoblené rohy; tlačidlá nemajú pôsobiť ako kapsule. Veľkosť a vnútorné odsadenie majú pohodlne umožniť kliknutie.
- Text tlačidla má byť krátky, konkrétny a dostatočne kontrastný. Hover a focus stav odlíš tmavším alebo svetlejším zeleným odtieňom, nie iba zmenou textu.
- Zachovaj jasnú vizuálnu hierarchiu: jedno primárne tlačidlo pre hlavný krok, sekundárne akcie nech sú menej výrazné.

## Celkový vizuálny dojem

Čistý, svieži e-shopový dizajn s bielym základom a výraznými zelenými akcentmi. Kombinácia sýtej zelenej `#387931` a jasnejšej `#76B729` pôsobí energicky a odkazuje na matchu; biele plochy a čitateľná typografia udržiavajú rozhranie prehľadné.

Uprednostni jasnú obsahovú hierarchiu, vzdušné rozloženie a kvalitné fotografie produktov. Dekoratívne prvky drž striedmo; zelené akcenty a fotografie majú dopĺňať obsah bez toho, aby súperili s textom alebo hlavnou akciou.
