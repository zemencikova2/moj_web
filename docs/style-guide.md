# Dizajnový manuál

Vizuálna referencia pre tvorbu webu podľa [Matcha Tea](https://www.matchatea.sk/). Cieľom je zachovať svieži, prírodný a pokojný charakter značky a prispôsobiť ho obsahu vlastného webu.

## Farebná paleta

| Farba | Odporúčaná úloha |
| --- | --- |
| `#183A2A` | Hlavná tmavozelená: primárne tlačidlá, výrazné nadpisy a dôležité odkazy. |
| `#527442` | Stredná zelená: sekundárne akcenty, odkazy, aktívne stavy a menšie grafické prvky. |
| `#A3B495` | Tlmená šalviová: jemné plochy, orámovania a dekoratívne detaily. |
| `#E5EAD9` | Svetlá zelená: pozadia vybraných sekcií, informačných blokov a jemne odlíšených plôch. |
| `#F7F5ED` | Hlavné teplé, takmer biele pozadie stránky. |
| `#E8E0D0` | Teplý béžový akcent pre drobné kontrastné plochy a doplnkové sekcie. |
| `#202820` | Základná farba textu; dobre čitateľná na svetlých pozadiach. |
| `#A6A6A6` | Vedľajší text, nenápadné popisy, deliace čiary a neaktívne prvky. |

Tmavé farby používaj na text a prvky, ktoré majú byť výrazné; svetlé odtiene nechávajú priestor obsahu a fotografiám. Dbaj na dostatočný kontrast textu, najmä pri menších veľkostiach.

## Písmo

- **Rodina písma:** Mulish. Referenčný web ju používa pre bežný text aj nadpisy.
- **Nadpisy:** Mulish v strednej až výraznej hrúbke; zreteľná hierarchia veľkostí, bez zbytočne dekoratívnych rezov.
- **Bežný text:** Mulish v normálnej hrúbke, pohodlná výška riadku a ľahko čitateľná šírka odsekov.
- **Záložné písmo:** `Arial, sans-serif`, ak Mulish nie je dostupný.

## Tlačidlá a ovládacie prvky

- Primárne tlačidlo má tmavozelené pozadie `#183A2A` a svetlý, dobre čitateľný text.
- Sekundárne tlačidlo môže byť zelené `#527442` alebo mať svetlé pozadie s tmavozeleným orámovaním.
- Použi mierne zaoblené rohy; tlačidlá nemajú pôsobiť ako kapsule. Veľkosť a vnútorné odsadenie majú pohodlne umožniť kliknutie.
- Text tlačidla má byť krátky, konkrétny a dostatočne kontrastný. Hover a focus stav odlíš tmavším alebo svetlejším zeleným odtieňom, nie iba zmenou textu.
- Zachovaj jasnú vizuálnu hierarchiu: jedno primárne tlačidlo pre hlavný krok, sekundárne akcie nech sú menej výrazné.

## Celkový vizuálny dojem

Čistý, svieži a pokojný dizajn inšpirovaný prírodou a matchou. Kombinuje hlboké zelené akcenty, jemné šalviové a krémové plochy, čitateľnú typografiu a dostatok voľného priestoru. Dojem má byť kvalitný a súčasný, nie prezdobený ani klinicky strohý.

Uprednostni jasnú obsahovú hierarchiu, vzdušné rozloženie a kvalitné fotografie, ktoré ukazujú skutočný obsah. Dekoratívne prvky drž striedmo; zelené odtiene a prírodná fotografia majú vytvárať atmosféru bez toho, aby súperili s textom alebo hlavnou akciou.
